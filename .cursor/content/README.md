# Content

This folder stores external or semi-structured content that we want to integrate or normalize into the website or `.cursor` knowledge base.

- Use for pasted notes, raw snippets, or third-party text before curation.
- Keep minimal headings; the agent will process and file them into proper artifacts (tasks, lessons, rules) when ready.
- Prefer English for permanence.

Conventions:
- If a content file is turned into a task/lesson/rule, add a note at the top with the shortcode reference(s), e.g. `[task:012]`, `[lesson:note-curation]`.
- Large raw dumps can live here temporarily; create follow-up tasks to curate them.
