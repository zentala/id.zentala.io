# Procedures

Authoritative, step-by-step guides for executing work. Always follow relevant procedures when working on tasks.

## Policy (Must-Follow)

- Never start work outside a `task-NNN.mdc`
- Define or refine the task until it is ready-to-do
- Execute using the appropriate procedure (e.g., `task-achieving.mdc`)
- Maintain a runbook during/after execution
- Update task status as you progress
- Extract lessons if reusable and link them
